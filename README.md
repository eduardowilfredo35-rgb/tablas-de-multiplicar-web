# tablas-de-multiplicar-web
Aplicación web interactiva para aprender y practicar las tablas de multiplicar de forma dinámica. Incluye un módulo de estudio visual con gráficos de puntos, práctica individual por tablas y retos mixtos contra reloj o por preguntas. Cuenta con personalización de avatares, temas, fondos y guardado automático de avance.
